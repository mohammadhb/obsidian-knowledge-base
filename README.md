# Obsidian Knowledge Base Template

Inspired By [karpathy's LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)

# Usage:
1. Create a repo using this template
2. Add documents to unprocessed folder in raw using [Obsidian Web Clipper](https://obsidian.md/clipper)
3. Tell your coding agents to `Process the files in the unprocessed folder and put it in my wiki then move them to processed folder`
4. See inside your wiki!
